Export ke Anki

Huruf yang sudah ditandai lancar. Format: depan → tab → belakang. Import di Anki: File → Import.

Cara pakai

  1. Pilih huruf → tonton animasi → tulis di canvas.
  2. Tekan +1 Tulisan setiap selesai 1× (atau setelah beberapa goresan). Target 5–10× per huruf.
  3. Kalau sudah nyaman, tekan Tandai Lancar.
  4. Klik Export Anki → salin / download → import ke Anki.
